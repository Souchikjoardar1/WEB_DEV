Web Technology Guide

Three building blocks of a browser interface.

HTML CSS JavaScript

HTML

HTML gives a page its structure and meaning. Headings, landmarks, and links help people and assistive technologies navigate that structure.

CSS

CSS controls presentation. This page uses Flexbox to place each illustration beside its description on wide screens and above it on narrow screens.

JavaScript

JavaScript adds behavior to a page. It can respond to user actions, update the document, and fetch data asynchronously.
